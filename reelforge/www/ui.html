YouTube channels

    
Each entry is one consent. Google lets you choose the account and the channel (including Brand Account channels) at the consent screen, so a second channel is just a second label.

    

    

      
      
    

    

  

  

    
Instagram

    
Needs a Business/Creator account linked to a Facebook Page, a long-lived token with instagram_content_publish, and the IG user id. Set them in Setup. Meta fetches the video from a URL, so publishing uses S3 if configured, otherwise a temporary Cloudflare tunnel if cloudflared is installed.
